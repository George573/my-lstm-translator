# English-to-French LSTM Translator

An educational neural machine translation project built from scratch with
PyTorch. It combines a custom byte-pair encoding (BPE) tokenizer with a
sequence-to-sequence LSTM that translates English text into French.

The repository is intentionally notebook-led: it shows the data preparation,
tokenizer training, model construction, and training experiments rather than
providing a production-ready translation service.

## What is included

- A custom BPE tokenizer with training, JSON persistence, caching, and optional
  multiprocessing for batch encoding.
- Pretrained English and French BPE vocabularies and merge rules.
- A bidirectional LSTM encoder and autoregressive LSTM decoder implemented in
  PyTorch.
- Teacher forcing, gradient clipping, validation, checkpointing, and early
  stopping in the training loop.
- An English-French sentence-pair corpus and a saved model checkpoint.

## Architecture

The translation pipeline is:

```text
English text
    -> English BPE tokenizer
    -> token embeddings
    -> bidirectional LSTM encoder
    -> bridged forward/backward hidden state
    -> autoregressive LSTM decoder
    -> French BPE tokens
```

The current notebook configuration uses a four-layer encoder/decoder, a hidden
size of 128, and 42-dimensional embeddings. These are experiment settings, not
requirements of the tokenizer or model design.

## Setup

Python 3.10 or newer is recommended. A CUDA-capable GPU is optional; the model
notebook automatically falls back to CPU.

```bash
git clone https://github.com/George573/my-lstm-translator.git
cd my-lstm-translator
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
jupyter lab
```

On Windows PowerShell, activate the environment with
`.venv\Scripts\Activate.ps1`.

PyTorch installation commands can vary by operating system and accelerator. If
the default package does not match your hardware, use the command generated by
the [official PyTorch installer](https://pytorch.org/get-started/locally/).

## Using the tokenizer

The pretrained tokenizers can be loaded without retraining:

```python
from lstm_translator import BPETokenizer

english = BPETokenizer.load("artifacts/tokenizers/en.json")
tokens = english.encode("Hello, how are you?")
print(tokens)

batch = english.encode_batch(
    ["A short sentence.", "Another sentence."],
    num_workers=1,
)
```

Train and persist a tokenizer with:

```python
from lstm_translator import BPETokenizer

tokenizer = BPETokenizer()
tokenizer.train(["text used to learn merge rules"], n_merges=1_000)
tokenizer.save("artifacts/tokenizers/my_tokenizer.json")
```

`num_workers=1` is best for small batches. Multiple workers can help with large
collections of unique words, but process startup has overhead.

## Training workflow

1. Create and activate the environment described above.
2. Open `notebooks/train_tokenizers.ipynb` to train new tokenizers, or use the
   included JSON tokenizer files.
3. Open `notebooks/train_model.ipynb` and run the model-definition cells.
4. Select the dataset source in the data-loading cell.
5. Tokenize the parallel sentences, construct the vocabularies, and train the
   model.

The tracked corpus can also be loaded from Python:

```python
from lstm_translator import load_parallel_tsv

en_texts, fr_texts = load_parallel_tsv("data/raw/fra.txt", num_samples=1.0)
```

The checkpoint contains only a PyTorch state dictionary. To load it, first run
the tokenizer, vocabulary, and model-definition cells so the architecture and
token-index mappings match, then call:

```python
model.load_model("artifacts/checkpoints/best_model.pth")
```

## Dataset

`data/raw/fra.txt` contains English-French sentence pairs from the Tatoeba
project. Each row stores the English sentence, French sentence, and source
attribution as tab-separated fields. Preserve that third field if you
redistribute derived datasets. The dataset's per-row attribution and license
information is separate from the software license in this repository.

## Current limitations

- This is an educational experiment and has not been benchmarked as a
  production translation system.
- The decoder does not currently use an attention mechanism.
- The complete training loop still lives in a notebook; the tokenizer, data
  loaders, and neural-network components are reusable Python modules.
- The saved checkpoint depends on the exact architecture and token ordering
  used when it was created.
- Punctuation is excluded by the tokenizer's current word-matching expression.
- Automated tests and standard translation metrics such as BLEU are not yet
  included.

## Ideas for future work
